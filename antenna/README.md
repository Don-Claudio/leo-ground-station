# Antenna

Design, modelling, build and measurement of the receive antenna for 137 MHz LEO weather satellites.

Intended design: a QFH or crossed-dipole turnstile with a reflector, chosen for wide beamwidth and circular polarization.

## Folders (created as needed)

- `models/`: simulation files (xnec2c, MMANA-GAL or 4NEC2)
- `results/`: pattern plots and SWR / VNA measurements
- `build/`: dimensions, cut list, photos
